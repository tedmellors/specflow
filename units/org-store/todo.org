* Implement

** NEXT Discovery: specflow-org-store-find-control-plane
   Given a buffer in a SpecFlow project,
   when =specflow-org-store-find-control-plane= is called,
   then it returns the absolute path to =docs/specflow.org=.

   Outcomes:
   - Searches upward from =default-directory=
   - Stops at project root (=.git=, =.projectile=, =.specflow-root=)
   - Falls back to =specflow-control-plane-path= variable
   - Signals =specflow-control-plane-not-found= if not found

** TODO Read: specflow-org-store-read-project-state
   Given a valid control plane file,
   when =specflow-org-store-read-project-state= is called,
   then it returns a plist with =:phase=, =:active-unit=, =:control-plane-path=.

   Outcomes:
   - Parses =SPEC_FLOW_PHASE= and =SPEC_FLOW_ACTIVE_UNIT= properties
   - Signals =specflow-control-plane-malformed= if required properties missing

** TODO Read: specflow-org-store-read-unit
   Given a unit name and control plane,
   when =specflow-org-store-read-unit= is called,
   then it returns the unit entry plist.

   Outcomes:
   - Returns plist with =:name=, =:spec=, =:todo=, =:rules=, =:parent=, etc.
   - Signals =specflow-unit-not-found= if unit not in registry
   - Signals =specflow-unit-malformed= if required properties missing
   - Returns =nil= for missing optional properties

** TODO Read: specflow-org-store-read-unit-registry
   Given a control plane file,
   when =specflow-org-store-read-unit-registry= is called,
   then it returns a list of all unit entry plists in document order.

** TODO Write: specflow-org-store-write-property
   Given a file path, heading path, property name, and value,
   when =specflow-org-store-write-property= is called,
   then the property is written with minimal diff.

   Outcomes:
   - Existing property: value replaced in-place
   - Missing property: inserted at end of drawer
   - Missing drawer: drawer created with property
   - No other file content modified (byte-for-byte)
   - Signals =specflow-heading-not-found= if heading invalid
   - Signals =specflow-file-not-writable= if cannot save

** TODO Validate: specflow-org-store-validate-unit-pointers
   Given a unit entry plist,
   when =specflow-org-store-validate-unit-pointers= is called,
   then it returns =t= if SPEC/TODO/RULES files exist, else signals error.

** TODO Validate: specflow-org-store-validate-parent-chain
   Given a unit name,
   when =specflow-org-store-validate-parent-chain= is called,
   then it returns list of ancestor names, or signals error if parent missing.
