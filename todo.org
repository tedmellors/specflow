** NEXT org-store: Refactor specflow-refine-task and specflow-activate-task behavior
   Given a backlog task selected by the user,
   when either command is called,
   then the task is moved from Backlog to Active section with refinement prompt.

   Behavior changes:
   - Both commands: move selected task from Backlog → Active (not just activate-task)
   - =specflow-refine-task=: keeps task as TODO in Active
   - =specflow-activate-task=: promotes task to NEXT in Active (demotes existing NEXT)

   Prompt changes:
   - Include full task body (headline + all content/notes beneath it)
   - Replace "Return only the revised task text" with instruction to edit todo.org
   - Final line: "Refine this task and update it in the root todo.org file."

   Outcomes:
   - Task moved from Backlog to Active in both cases
   - Kill-ring prompt includes task body for context
   - Prompt instructs Claude to edit the file directly
   - Update ERT tests and README.md
